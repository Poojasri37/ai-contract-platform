# 📄 AI Contract Assistant Pro: Distributor Intelligence Platform

## Overview

The **AI Contract Assistant Pro** is a Streamlit web application designed to accelerate the analysis of large volumes of distributor or legal contracts. It uses a **Retrieval-Augmented Generation (RAG)** architecture with Groq and Hugging Face Embeddings to provide real-time Q\&A, structured summaries, and automated alerts directly from PDF documents.

This application effectively merges powerful backend AI with a professional, interactive business intelligence (BI) dashboard interface.

## ✨ Key Features

| Module | Description | Technical Core |
| :--- | :--- | :--- |
| **💬 Chat Assistant** | Real-time Q\&A against the entire document portfolio. Answers are grounded *only* in the text of the processed PDFs. | **RAG Pipeline** (HuggingFace Embeddings + Groq LLM) |
| **📰 Summarizer** | Generates structured, concise summaries for key topics (Margins, SLAs, Expiration Dates, Flags) for easy review. | **LLM Prompting** via Search/Context |
| **🚨 Alerts** | **Automated detection of timelines.** Compares contract expiration/renewal dates (extracted from summaries) against the current system date to show "Days Left" or "Past Due" status. | Date Extraction (Regex) & `datetime` comparison |
| **📊 Executive Dashboard** | Provides high-level metrics and visualizations (Mock Data) demonstrating portfolio performance and profit opportunities. | Streamlit, Pandas, Plotly |
| **🔄 Rebuild Logic** | Handles new document processing, including **duplicate content checks** with user confirmation before adding data to the VectorDB. | File Hashing (SHA256) & `VectorDB` |

## 🚀 Setup and Deployment

This application is designed to be easily containerized using Docker, which is highly recommended for stable deployment.

### Prerequisites

1.  **Python 3.10+** (Python 3.11 is recommended for stability).
2.  **Docker Desktop** (for deployment).
3.  A **Groq API Key** (for fast LLM responses).

### Step 1: Clone the Repository and Configure

```bash
# 1. Clone the project (assuming it's in a Git repository)
git clone <your-repository-url>
cd hack

# 2. Create the environment file
touch .env
````

Add your Groq API key to the `.env` file:

```
GROQ_API_KEY="YOUR_GROQ_API_KEY_HERE"
```

### Step 2: Organize the File Structure

Ensure your project root contains the necessary files and empty data directories.

```
hack/
├── app.py
├── dashboard.py
├── Dockerfile
├── requirements.txt
├── .env
├── source_documents/   # <- Place your PDF files here (e.g., 54.pdf, DISTRIBUTOR_A.pdf)
├── summary/            # <- Auto-generated by the app
└── multi_document_db/  # <- Auto-generated by the app (VectorDB)
```

### Step 3: Build and Run with Docker (Recommended)

Using Docker guarantees that all libraries and system dependencies (like those needed for PyMuPDF) are correctly configured.

1.  **Build the Image:**

    ```bash
    docker build -t contract-assistant-app .
    ```

2.  **Run the Container:** This runs the app and exposes it on port 8501.

    ```bash
    docker run -p 8501:8501 contract-assistant-app
    ```

3.  **Access the App:** Open your web browser and navigate to `http://localhost:8501`.

### Initial Usage After Launch

1.  Go to the **Controls** sidebar.
2.  Click the **"🔄 Process New Documents (Rebuild)"** button.
3.  The app will load your PDFs, generate vector embeddings, create structured summaries (including the **Expiration Date** needed for alerts), and save the database.
4.  Navigate to the **🚨 Alerts** tab to see your active deadlines and the **📊 Executive Dashboard** for initial analytics.

## 🛠️ Technical Dependencies

The core components of this project include:

  * **Frontend/App Framework:** `streamlit`
  * **LLM Provider:** `langchain-groq` (using `llama-3.1-8b-instant`)
  * **Embeddings:** `langchain-huggingface` (`all-MiniLM-L6-v2`)
  * **Vector Database:** Custom `VectorDB` class (using `numpy` arrays for storage and cosine similarity)
  * **PDF Handling:** `PyMuPDF` (via `fitz`)
  * **Data/Viz:** `pandas`, `plotly`
